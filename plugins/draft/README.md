# draft

The writing studio of the smithy family. Writes books, poetry,
technical articles, and repo documentation, reviews prose, and
compiles ebooks.

**Requires the forge plugin.** Draft's skills extend
`forge:writing-style` and borrow `forge:citations`,
`forge:web-browsing`, `forge:conventional-commits`, and
`forge:adversarial-review` by name. Install and enable forge
wherever draft runs.

- `/draft:write [task]` writes manuscript content or articles in the
  project's own voice.
- `/draft:publish [format]` compiles the manuscript into EPUB for
  KDP and Nook. Local files only.
- `/draft:docs [task]` writes repo documentation, verified against
  the code it describes.
- `/draft:review [path or glob]` reviews prose files through the
  prose lens pack of `forge:adversarial-review`. Findings and one
  verdict, never an edit.

Enable per repo in writing projects and anywhere documentation is
the deliverable.
